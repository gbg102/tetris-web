# 테트리스 (Tetris)

브라우저에서 바로 플레이할 수 있는 클래식 테트리스 웹 게임입니다.

## 실행 방법

`index.html` 파일을 브라우저에서 열거나, 로컬 서버로 실행하세요.

```bash
python -m http.server 8765
```

브라우저에서 `http://localhost:8765` 로 접속합니다.

## 조작법

| 키 | 동작 |
|---|---|
| ← → | 좌우 이동 |
| ↑ | 회전 |
| ↓ | 소프트 드롭 |
| 스페이스 | 하드 드롭 |
| C | 홀드 |
| P | 일시정지 |

## 기능

- 7가지 테트로미노
- 점수, 레벨, 라인 표시
- 다음 블록 미리보기
- 홀드 기능
- 고스트 피스 (착지 위치 표시)
- 레벨 상승 시 낙하 속도 증가
